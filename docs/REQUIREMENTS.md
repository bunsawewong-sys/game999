# Firewall Defender — Requirement (v1)

สรุปจากการสอบถามกอล์ฟ (2026-10-19)

## 1. ภาพรวม

| หัวข้อ | รายละเอียด |
|---|---|
| แนวเกม | Vertical Space Shooter (ยานอยู่ล่างจอ ศัตรูลงมาจากด้านบน) |
| ธีม | Network / Cyber: ผู้เล่นเป็น Firewall ป้องกันเครือข่ายจาก Packet ขยะ, Virus, Botnet |
| Platform | Web Game เปิดเล่นผ่าน browser มือถือ จอแนวตั้ง (Portrait) |
| เป้าหมาย | ทำเล่นเอง / ทดลอง |
| ความยาว 1 รอบ | 5-10 นาที |
| ความยาก | โหมดเดียว ยากขึ้นตามจำนวน Wave |

## 2. Gameplay

- **การควบคุม:** ลากนิ้วเพื่อเคลื่อนที่ (ยานขยับตามระยะที่ลากนิ้ว นิ้วไม่บังยาน) ยิงอัตโนมัติตลอด
- **โครงสร้าง:** Wave ละประมาณ 40-60 วินาที มี Boss ทุก 3 Wave วนไปเรื่อยๆ และยากขึ้นในแต่ละรอบ
- **ชีวิต:** HP Bar โดนยิงเลือดลด เก็บไอเทมฟื้นเลือดได้
- **Meta progression:** ไม่มี ทุกรอบเริ่มจากศูนย์เท่ากัน
- **คะแนน:** ฆ่าศัตรู + โบนัสชนะ Boss + โบนัสจบ Wave โดยไม่โดนยิง

## 3. เนื้อหา

### ศัตรู 5 แบบ

| ชื่อ | พฤติกรรม | ปลดล็อก |
|---|---|---|
| Spam Packet | เคลื่อนลงตรงๆ ช้าๆ | Wave 1 |
| ICMP Ping | ตัวเล็ก เร็ว มาเป็นฝูงรูปตัว V | Wave 1 |
| Worm | เคลื่อนซิกแซกเป็นขบวน | Wave 2 |
| Trojan | ปลอมเป็น Packet สีเขียว แล้วเผยตัวยิงสวน | Wave 4 |
| Virus | ตายแล้วแตกเป็นตัวเล็ก 2 ตัว | Wave 5 |

### Boss 3 ตัว (วนสลับ)

| Wave | Boss | กลไก |
|---|---|---|
| 3, 12, 21... | DDoS Core | ปล่อยฝูง Ping, ยิงกระสุนเป็นวง |
| 6, 15, 24... | Ransomware | มีเกราะ Encrypt เป็นช่วงๆ ยิงได้เฉพาะตอนเกราะเปิด, ยิงเกลียว |
| 9, 18, 27... | Botnet C&C | มี Bot Node ลูกน้องโคจรรอบตัวยิงเล็ง, ยิงเลเซอร์แนวตั้ง (มีเส้นเตือนก่อน) |

หลังจากรอบแรกจะวนกลับไปตัวแรก โดยเพิ่ม HP และความเร็ว

### Power-up ดรอปจากศัตรู (ชั่วคราว)

| ชื่อ | ผล |
|---|---|
| Multicast | ยิง 3 ทาง |
| Fiber Laser | เลเซอร์ทะลุศัตรู |
| DMZ Shield | โล่กันความเสียหาย |
| Patch | ฟื้น HP ทันที |
| QoS Boost | ยิงเร็วขึ้น 2 เท่า |

### การ์ดอัปเกรดหลังจบ Wave (สุ่ม 3 เลือก 1)

| Load Balancer | ป้อมยิงเสริมด้านข้าง | 2 |

| Auto-Discovery | ดูดไอเทมจากระยะไกลขึ้น | 3 |
| Zero-day Exploit | +10% โอกาส Critical (x2) | 5 |

## 4. ภาพ เสียง ภาษา

- **ภาพ:** Pixel Art Retro วาดด้วยโค้ด (ไม่ใช้ไฟล์ภาพภายนอก)
- **เสียง:** SFX + BGM แนว chiptune สร้างด้วย Web Audio
- **ภาษา:** ไทย / English สลับได้
- **ฟีเจอร์เสริม:** Pause + Settings (ปรับเสียง SFX/BGM แยกกัน, สลับภาษา)

## 5. Leaderboard

- พิมพ์ชื่อเล่น 3-12 ตัวอักษร จำไว้ในเครื่อง ไม่ต้องสมัคร
- All-time Top 50 (เก็บคะแนนดีที่สุดต่อชื่อ)
- ไม่มีระบบกันโกง (ตรวจรูปแบบข้อมูลพื้นฐานเท่านั้น)
- ถ้ายังไม่ได้ต่อ Database ใช้ Leaderboard ในเครื่องแทนอัตโนมัติ
